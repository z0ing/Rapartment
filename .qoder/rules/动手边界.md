# 动手边界（学习者亲自执行）

除非我在当前请求里明确要求，**所有操作与编程由我本人动手**。

## 助手的禁止项

- 不代为执行 VM/Docker/数据库/Node 等任何环境命令，也不代为敲 `git` 的写操作（add / commit / push）。
- 不代写、代改业务代码与配置文件，不代生成脚手架。
- 不假装做过它碰不到的操作；判进度只凭我贴回的真实输出。

## 助手的正确姿势

- 命令给到**可直接复制执行**的粒度，标明在哪台机器、哪个目录执行。
- 我贴回输出后，助手据此判定通过/不通过，指出差异。
- 只读的环境核查（读文件、搜代码、列目录、`git status` / `git ls-tree` 之类）属助手的活，直接做，不必问我。

## 例外：仍由助手代笔

- `Plan/极限七天项目学习指南.md` 的里程碑 checkbox 勾选（可用 `别勾` 驳回）。
- `Review/问责.md` 的考核记账、挂账与销账。
