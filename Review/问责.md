# 项目问责点

| 内容       | 要回答的问题                                       | 何时填（里程碑） |
| ---------- | -------------------------------------------------- | ------------ |
| 业务背景   | 项目给谁使用，解决什么问题，核心链路是什么         | M1 / M4 |
| 个人职责   | 哪些接口、表、任务或模块由自己负责，参与到什么程度 | M2 / M4（本冲刺=跑通·读懂·部署·复现·改了登录链X处） |
| 请求链路   | 一次请求经过哪些服务、缓存、数据库和消息队列       | M2（登录链）/ M4 |
| 技术选型   | 为什么采用当前方案，比较过什么，付出了什么代价     | M2 / M3 |
| 难点或故障 | 现象是什么，怎样定位、修复和验证                   | 全程随手记 |
| 项目指标   | 数据来自生产还是测试，统计口径和对照条件是什么     | M6（如做缓存对比则 Phase-2） |
| 职责范围   | 哪些部分由其他同事或团队负责                       | M4 |
